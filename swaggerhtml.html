Recipes

Up 
get /recipes/{recipeId}
Get recipe by ID (getRecipeById)
Retrieve a single recipe by its ID.

Path parameters

recipeId (required)
Path Parameter — ID of the recipe to retrieve

Return type

Recipe

  "summary" : "summary",
  "image" : "image",
  "instructions" : "instructions",
  "servings" : 5,
  "vegetarian" : true,
  "glutenFree" : true,
  "id" : "id",
  "vegan" : true,
  "title" : "title",
  "extendedIngredients" : [ {
    "amount" : 5.962133916683182,
    "unit" : "unit",
    "name" : "name",
    "id" : 1
  }, {
    "amount" : 5.962133916683182,
    "unit" : "unit",
    "name" : "name",
    "id" : 1
  } ],

}

This API call produces the following media types according to the Accept request header; the media type will be conveyed by the Content-Type response header.

Users

Up 
post /users/login
User login (loginUser)
Authenticate a user and return a token.

Consumes

This API call consumes the following media types via the Content-Type request header:
  • application/json

Request body

body LoginUser (required)
Body Parameter — User credentials
example: { "username" : "existinguser", "password" : "password123" }

Return type

inline_response_200

Example data

Content-Type: application/json
{
  "token" : "token"
}

Produces

This API call produces the following media types according to the Accept request header; the media type will be conveyed by the Content-Type response header.
  • application/json

Responses

200

Login successful inline_response_200

Example data

Content-Type: application/json
{"token":"eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."}

401

Invalid credentials

Example data

Content-Type: application/json
{"message":"Invalid username or password"}
Up 
post /users/register
Register a new user (registerUser)
Create a new user account.

Consumes

This API call consumes the following media types via the Content-Type request header:
  • application/json

Request body

body NewUser (required)
Body Parameter — User details for registration
example: { "username" : "newuser", "password" : "SecureP@ssw0rd", "email" : "newuser@example.com", "firstName" : "John", "lastName" : "Doe" }

Return type

User

Example data

Content-Type: application/json
{
  "firstName" : "firstName",
  "lastName" : "lastName",
  "id" : "id",
  "email" : "email",
  "username" : "username"
}

Produces

This API call produces the following media types according to the Accept request header; the media type will be conveyed by the Content-Type response header.
  • application/json

Responses

201

User registered successfully User

Example data

Content-Type: application/json
{"id":"123","username":"newuser","email":"newuser@example.com","firstName":"John","lastName":"Doe"}

400

Invalid input

Example data

Content-Type: application/json
{"message":"Invalid user data"}
